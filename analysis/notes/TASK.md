# Engineer Recruitment Task Sep 2026

## Before You Start

This recruitment at KTH with Prof. Monperrus is extremely competitive. The bar is very high, and most submissions will not lead to an offer. Only the most rigorous, insightful, and clearly communicated results will stand out.

---

## The Task

Your task is to study and extend https://github.com/chopratejas/headroom

---

## What You Should Do

### 1. Run the code
Read the repo carefully. Make sure you run the main functionalities.

### 2. Propose a meaningful extension
Identify a gap or a potentially useful new feature. Implement a proof of concept. You don't have to propose it upstream, but feel free to do so.

### 3. Evaluate and analyze the extension
Select a coding agent and some benchmark tasks to quantitatively measure the effect of your proposal.

### 4. Write up your findings
Produce a `ANALYSIS.md` summarizing:
- The most interesting features you were able to exercise.
- Your extension
- Your evaluation

---

- A **GitHub repository**, fork of headroom. If the fork is private, share it with GitHub user `monperrus`.
- An `ANALYSIS.md` in the repo with **at most 3000 words** . This is the primary artifact we will evaluate. The readme should appropriately hyperlink to the underlying code and data.

## What We Are Looking For

We will evaluate your submission on:

1. **Technical correctness** — Are the results soundly reported?

2. **Evaluation rigor** — Is the eval designed and executed with appropriate depth and rigor?

3. **Clarity** — Is `ANALYSIS.md` well-written and precise? Do you clearly distinguish what you implemented, what you found, and what remains uncertain?
